# Dicionário Inglês-Português

Um dicionário simples em Python para traduzir palavras do inglês para o português.

## Funcionalidades

*   Tradução de palavras do inglês para o português
*   Dicionário com palavras comuns em Data Science

## Como Usar

1.  Clone o repositório com `git clone https://github.com/tluistorres/Dicionario_ingles.git`
2.  Execute o script Python com `python dicionario.py`
3.  Digite uma palavra em inglês para obter a tradução em português
